# Non-EVM Chains

RedStone's price feeds are not limited to EVM-compatible chains. The same data — sourced, aggregated, and signed the same way — is also delivered to non-EVM ledgers, using integration models adapted to each chain's architecture.

## Supported Chains

### [Canton](./canton/index.mdx)

Push and pull models adapted to Canton's privacy-by-design ledger, where each participant node sees only the contracts and data it is involved in.

### [Solana](./solana/index.mdx)

A price adapter program and price feed accounts for consuming RedStone data on Solana.

### [Stellar](./stellar/index.mdx)

A Stellar connector with Rust and TypeScript integration guides, audited by Veridise and Zellic.

### [Sui](./sui/index.mdx)

A Sui connector with Move and TypeScript integration guides.

If you're integrating on a non-EVM chain not listed here, [contact RedStone](https://redstone.finance/contact) to discuss support.
